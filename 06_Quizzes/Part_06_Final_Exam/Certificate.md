# Nmap Master Academy Certificate

> This certificate recognizes the successful completion of the **Nmap Master Academy** learning program.

---

# Certificate Overview

The Nmap Master Academy Certificate is awarded to learners who have successfully completed the entire curriculum, including theoretical study, practical laboratories, quizzes, and the comprehensive final examination.

The certificate represents dedication to structured learning and practical understanding of Nmap and network reconnaissance techniques.

---

# Eligibility Requirements

To earn this certificate, learners should complete all sections of the academy.

Required components include:

- Complete Course Chapters
- Complete NSE Lessons
- Complete Reference Materials
- Complete Hands-on Labs
- Complete Section Quizzes
- Pass the Final Examination

---

# Completion Criteria

A learner is considered to have successfully completed the academy after:

- Studying all course content
- Completing all practical laboratories
- Finishing every quiz section
- Achieving at least **75%** on the Final Examination

---

# Skills Demonstrated

Successful learners demonstrate knowledge of:

- Networking Fundamentals
- TCP/IP
- OSI Model
- Host Discovery
- Port Scanning
- TCP and UDP Scanning
- Service Version Detection
- Operating System Detection
- NSE (Nmap Scripting Engine)
- Output Formats
- Infrastructure Assessment
- Enterprise Reporting
- Scan Automation
- Bash Automation
- Python Automation
- XML Processing
- Professional Documentation

---

# Academic Integrity

This certificate reflects completion of the educational material.

It does **not** certify professional penetration testing experience or authorize offensive security activities.

Learners are expected to perform security testing only against systems they own or are explicitly authorized to assess.

---

# Recommended Next Steps

After completing the academy, learners are encouraged to continue with:

- Wireshark
- Burp Suite
- Gobuster
- FFUF
- SQLMap
- Metasploit Framework
- Active Directory Enumeration
- Web Application Security
- Linux Administration
- Python for Security Automation
