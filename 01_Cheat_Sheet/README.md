# Nmap Cheat Sheet

> A comprehensive quick reference guide covering the most commonly used Nmap commands, scan techniques, options, and best practices.

---

## Overview

The **Cheat Sheet** is designed as a fast reference for students, penetration testers, system administrators, and cybersecurity professionals.

Instead of explaining concepts in depth, this section provides concise command references and practical examples that can be quickly consulted during learning, labs, or real-world assessments.

Whether you need to remember a scan option, review syntax, or compare different scan techniques, this guide serves as a practical companion throughout your Nmap journey.
