# Security Policy

## Supported Versions

Security updates apply to the latest version of this repository.

## Reporting a Vulnerability

If you discover a security issue within this repository:

- Do not publish it publicly.
- Open a private security report if available.
- Clearly describe the issue.
- Include reproduction steps if applicable.

The maintainers will review the report and respond as soon as possible.

## Scope

This repository primarily contains educational documentation and example materials.

If a vulnerability affects any included scripts or sample code, please report it responsibly.
