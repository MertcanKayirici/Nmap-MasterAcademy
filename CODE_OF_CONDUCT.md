# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in this project.

## Our Standards

Examples of positive behavior include:

- Being respectful and constructive.
- Welcoming newcomers.
- Providing helpful feedback.
- Respecting different opinions and experiences.
- Focusing on learning and collaboration.

Examples of unacceptable behavior include:

- Harassment or discrimination.
- Personal attacks.
- Trolling or insulting language.
- Publishing private information.
- Any behavior considered inappropriate in a professional environment.

## Enforcement

Project maintainers have the right to remove, edit, or reject contributions that violate this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces, discussions, issues, pull requests, and community interactions.

## Contact

If you experience unacceptable behavior, please open a confidential discussion with the project maintainers.
