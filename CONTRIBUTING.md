# Contributing

Thank you for your interest in contributing to the Nmap Master Academy.

## Ways to Contribute

You can contribute by:

- Fixing documentation errors
- Improving explanations
- Reporting issues
- Suggesting new labs
- Adding references
- Improving diagrams
- Creating quizzes
- Correcting grammar or formatting

## Contribution Guidelines

Before submitting a Pull Request:

1. Read the existing documentation.
2. Keep formatting consistent.
3. Use clear English.
4. Verify technical accuracy.
5. Test any commands before adding them.

## Pull Requests

Please include:

- A clear description.
- The purpose of the change.
- Related issue (if applicable).

## Documentation Style

- Use Markdown.
- Keep headings consistent.
- Prefer examples.
- Explain concepts clearly.
- Avoid unnecessary repetition.

Thank you for helping improve this educational project.
