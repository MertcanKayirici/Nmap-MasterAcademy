# Nmap Master Academy — Labs

> Hands-on laboratories designed to transform theoretical Nmap knowledge into practical assessment skills through structured, real-world exercises.

---

# Overview

The **Labs** section is the practical component of the **Nmap Master Academy**.

Throughout these laboratories, you will progress from basic host discovery to enterprise-scale automated assessments.

Unlike traditional tutorials that focus only on commands, these labs emphasize:

- Structured methodologies
- Repeatable workflows
- Professional documentation
- Evidence-based analysis
- Real-world assessment practices

Every lab is designed to reinforce concepts learned in the Course section while introducing practical scenarios that resemble authorized security assessments.

# Laboratory Categories

## Part 01 — Basic Scanning

Learn the foundations of Nmap.

Topics include:

- Host Discovery
- Basic Port Scanning
- TCP vs UDP
- Service Enumeration

---

## Part 02 — Enumeration

Learn how to identify systems and services.

Topics include:

- Service Detection
- Operating System Detection
- Aggressive Scan
- Output Formats
- Full Enumeration

---

## Part 03 — Nmap Scripting Engine (NSE)

Learn to gather detailed information using NSE.

# Recommended Workflow

For every lab:

```
Read Theory

↓

Understand the Scenario

↓

Perform the Assessment

↓

Analyze Results

↓

Document Findings

↓

Complete the Challenge

↓

Review Key Takeaways
```

Avoid skipping directly to the challenge.

The learning value comes from understanding each step of the assessment process.

---

# Best Practices

Throughout these laboratories:

- Work only in authorized environments.
- Document every command you execute.
- Record observations before drawing conclusions.
- Validate findings using multiple sources when appropriate.
- Preserve raw scan results.
- Produce clear and structured reports.
- Focus on methodology rather than memorizing commands.

# Before You Begin

Ensure that you:

- Understand the fundamentals of TCP/IP networking.
- Have permission to assess the target environment.
- Use an isolated laboratory whenever possible.
- Keep detailed notes throughout every exercise.

# Final Goal

The objective of these laboratories is not simply to learn Nmap commands.

The goal is to develop a professional, repeatable methodology for:

- Discovering hosts
- Enumerating services
- Analyzing infrastructure
- Documenting findings
- Automating assessments

By the end of this laboratory series, you will be able to approach authorized network assessments with a structured workflow that scales from individual hosts to enterprise environments.
