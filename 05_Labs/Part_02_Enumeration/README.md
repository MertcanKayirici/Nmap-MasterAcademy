# Part 02 — Enumeration

> Learn how to identify services, operating systems, and valuable information from target hosts using Nmap.

---

# Overview

After discovering live hosts and identifying open ports, the next phase is **Enumeration**.

Enumeration is the process of collecting detailed information about a target system.

Instead of simply asking:

"Which ports are open?"

You begin asking questions such as:

- Which operating system is running?
- Which services are installed?
- Which versions are in use?
- Are there any known vulnerabilities?
- Can additional information be collected automatically?

Enumeration transforms a simple port scan into meaningful intelligence.
