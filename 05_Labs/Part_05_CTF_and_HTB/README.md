# Part 05 — CTF and Hack The Box

> Apply Nmap in Capture The Flag (CTF) platforms and realistic training environments using professional reconnaissance methodologies.

---

# Overview

Real-world security assessments require structured reconnaissance.

Training platforms such as Hack The Box (HTB), TryHackMe (THM), and Capture The Flag (CTF) challenges provide safe environments to practice these skills.

This section demonstrates how Nmap fits into the early stages of an assessment.

Rather than focusing on exploitation, these labs emphasize:

- Host discovery
- Port scanning
- Service detection
- Enumeration
- Technology identification
- Infrastructure analysis
- Documentation

The methodology remains the same regardless of the platform.

---

# Learning Objectives

After completing this section, you will be able to:

- Apply Nmap in Hack The Box
- Use Nmap effectively in TryHackMe
- Approach CTF machines systematically
- Build repeatable reconnaissance workflows
- Document enumeration results
