# Part 04 — Real World Assessments

> Apply Nmap in realistic environments using structured reconnaissance and enumeration workflows.

---

# Overview

Previous parts focused on learning individual Nmap features.

This section combines those skills into complete assessment scenarios inspired by real-world environments.

Rather than learning isolated commands, you will learn how to think like a network administrator or security analyst.

Each lab follows a practical workflow:

- Understand the environment
- Discover hosts
- Identify services
- Enumerate systems
- Analyze findings
- Document observations

---

# Learning Objectives

After completing this section, you will be able to:

- Assess internal networks
- Enumerate Windows servers
- Analyze Linux servers
- Investigate web servers
- Review database servers
- Examine DMZ environments
- Produce structured assessment reports
