# Part 01 — Basic Scanning

> Learn the fundamentals of Nmap by performing your first practical network scans in a safe lab environment.

---

# Overview

Welcome to the first laboratory section of the **Nmap Master Academy**.

Unlike the **Course** section, where concepts are explained theoretically, the **Labs** section focuses on practical application.

This part introduces the essential scanning techniques that every network engineer, system administrator, SOC analyst, and penetration tester should master before moving on to advanced enumeration and scripting.

Every lab is designed to simulate realistic situations while remaining beginner-friendly.

---

# Objectives

By completing this section, you will be able to:

- Prepare a safe penetration testing lab
- Discover live hosts on a network
- Perform basic TCP and UDP scans
- Identify open ports
- Detect running network services
- Interpret Nmap output
- Save scan results for later analysis

# Best Practices

- Scan only systems you own or have permission to test.
- Never perform unauthorized scans on public networks.
- Save your scan results for future comparison.
- Read the output carefully before moving to the next lab.
