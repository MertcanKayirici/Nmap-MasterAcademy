# Nmap Course

> A complete step-by-step learning path designed to teach Nmap from networking fundamentals to professional penetration testing workflows.

---

## Overview

The **Course** section is the core learning path of the **Nmap Master Academy**.

Each lesson builds upon the previous one, gradually introducing new concepts, scan techniques, and practical methodologies. The goal is to develop a solid understanding of how Nmap works and how it is used during professional security assessments.

Unlike the Cheat Sheet, which serves as a quick reference, this section provides detailed explanations, examples, diagrams, and best practices for every topic.

---

## Learning Objectives

After completing this course, you will be able to:

- Understand the fundamentals of computer networking
- Explain how TCP/IP communication works
- Perform host discovery efficiently
- Scan ports using different techniques
- Detect services and software versions
- Identify operating systems
- Use the Nmap Scripting Engine (NSE)
- Optimize scan performance
- Understand firewall interactions
- Produce professional scan reports
- Apply Nmap in real-world penetration testing engagements

## Prerequisites

No prior Nmap experience is required.

Basic knowledge of the following topics is helpful:

- Computer networking
- IP addressing
- TCP/IP
- Operating systems
- Command-line usage

---

## Best Practices

To get the most out of this course:

- Complete lessons in order.
- Practice every command in a lab environment.
- Take notes while learning.
- Repeat important scans until you understand the output.
- Avoid skipping foundational chapters.
- Review previous lessons before moving to advanced topics.
